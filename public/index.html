🚀 Integrate With Your Application

        
      

      

        
Send a batch of logs (e.g. all logs from the last 2 seconds) in one POST:

        

          
          
          
        

        

          
// Accumulate logs for 2s then send batch
const buffer = [];
const WINDOW_MS = 2000;

logger.on('data', (log) => buffer.push(log));

setInterval(async () => {
  if (buffer.length === 0) return;
  const batch = buffer.splice(0, buffer.length);
  await fetch('http://localhost:3000/api/logs/batch', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ logs: batch, windowMs: WINDOW_MS })
  });
}, WINDOW_MS);

        

        

          
import threading, requests, time

buffer = []
WINDOW_SEC = 2

def flush():
    while True:
        time.sleep(WINDOW_SEC)
        if not buffer: continue
        batch = buffer[:]
        buffer.clear()
        requests.post('http://localhost:3000/api/logs/batch', json={
            'logs': batch, 'windowMs': WINDOW_SEC * 1000
        }, timeout=10)

threading.Thread(target=flush, daemon=True).start()

🧠 Why Batch AI over Regex/Rules?

        
      

      

        

          

            
📏Traditional Regex / Rules

            
    
              
  • ✅ Catches password=abc123 — keyword match
    • 
              
  • ✅ Catches OOM error — exact string
    • 
              
  • ✅ Free to run — no API cost
    • 
              
  • ❌ Misses "my DB creds are admin/secret"
    • 
              
  • ❌ Can't detect cross-log patterns in a batch
    • 
              
  • ❌ Can't score overall system health across 100 logs
    • 
              
  • ❌ 50 busy connections — critical or not? Depends on context
    • 
              
  • ❌ New log format = new rules to write
    • 
              
  • ❌ No holistic "is this window about to cause an outage?" judgment
    •

    • 
              
  • ✅ System health score across the entire window
    • 
              
  • ✅ Understands slang, abbreviations, any language/framework
    • 
              
  • ✅ Context-aware severity: same log = different risk in different apps
    • 
              
  • ✅ Output tokens = 0 → you only pay for input
